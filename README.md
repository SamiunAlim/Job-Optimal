# Job Optimal Frontend (React)

This is the React.js version of the Job Optimal platform.

## 🚀 Getting Started

1.  Navigate into the frontend directory:
    ```bash
    cd frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

## 📂 Project Structure
*   `src/pages`: Contains the main screens (Landing, Login, Dashboards).
*   `src/App.jsx`: Main routing and layout.
*   `src/index.css`: Global glassmorphism design system.

## 🔌 Backend Integration
If you want to connect this React app to your existing PHP backend:
1.  Enable CORS in your PHP files.
2.  Use `fetch()` or `axios` in the React components to call your PHP endpoints.
